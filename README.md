# To-Do List Application

A simple and interactive To-Do List application built using HTML, CSS and Vanilla JavaScript.

## Project Overview

This project helps users manage their daily tasks through a simple and clean user interface.

It uses JavaScript to handle task interactions and Local Storage to save tasks in the browser.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Functionality and DOM manipulation
- Local Storage – Saving tasks in the browser

## Features

- Simple and clean user interface
- Add and manage daily tasks
- Store tasks using browser Local Storage
- Dark-themed design
- Interactive task management
