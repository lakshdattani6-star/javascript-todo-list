# My To-Do List

A simple and interactive To-Do List web application built using HTML, CSS and Vanilla JavaScript.

## Live Demo

https://laksh-todo-list.netlify.app/

## Project Overview

My To-Do List is a task management application that allows users to add and organize their daily tasks through a simple interface.

## Features

- Add new tasks
- View all tasks
- Filter pending tasks
- Filter completed tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
